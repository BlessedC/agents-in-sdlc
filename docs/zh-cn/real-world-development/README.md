通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代规划更改、编写代码、测试行为、审查 pull request，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游众筹提供平台，并以开发者为主题。团队的待办事项已作为 GitHub issues 创建好，供你认领。其中既有筛选和分页等功能开发，也有无障碍和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择符合你构建方式的环境。每个工作坊都有各自的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot 应用][app]

在桌面应用中运行并行代理会话、切换会话模式、协作处理画布，以及管理 GitHub issues 和 pull request。

### [GitHub Copilot 云代理][cloud]

将 GitHub issue 分配给异步代理，引导其工作、监控进度，并审查它创建的 pull request。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
