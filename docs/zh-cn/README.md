根据学习目标和探索深度选择工作坊。**入门**将引导你了解 GitHub Copilot；**真实开发场景**则使用完整应用和团队待办事项，练习面向生产环境的工作流。

## 入门

通过聚焦、循序渐进的体验，了解 GitHub Copilot 产品的主要功能，无需准备现有代码库。

### [GitHub Copilot 应用导览][first-steps-app]

从空文件夹开始构建 Space Quiz，将其发布到 GitHub，处理一个 issue，完成 Copilot 代码审查，安排自动化任务，并探索 Canvas 工作流。

### [GitHub Copilot CLI 入门][first-steps-cli]

在终端中构建同一个 Space Quiz、审查差异、在 worktree 中运行并行会话、编辑前先制定计划，并在不离开 shell 的情况下创建、合并和委派 pull request。

### [Visual Studio Code 入门][first-steps-vscode]

在 VS Code 中构建 Space Quiz，使用集成浏览器测试，通过源代码管理发布，使用 GitHub 工具处理 issues 和 pull request，并将工作移交给云会话。

## 真实开发场景

使用 Tailspin Toys 应用和待办事项，体验真实的软件开发生命周期中的 GitHub Copilot。选择工作环境，然后规划、构建、测试、审查并交付有意义的更改。

### [浏览真实开发场景工作坊][real-world-development]

可选择 GitHub Copilot CLI、GitHub Copilot 应用、GitHub Copilot 云代理或 Visual Studio Code。

> [!CAUTION]
> GitHub Copilot 具有概率性而非确定性，因此具体代码和修改的文件可能与示例不同。出现细微差异属于正常现象。
>
> 如果在讲师指导的研讨会中遇到无法正常运行的内容，请向导师求助。
